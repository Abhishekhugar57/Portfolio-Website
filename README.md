# Portfolio Website

Personal portfolio of **Abhishek Hugar** — Full Stack MERN Developer.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Live Demo

Deploy the `dist` folder after running `npm run build`, or connect the repo to [Vercel](https://vercel.com) / [Netlify](https://netlify.com) for automatic deployments.
